# Queue Implementation in C++

A simple implementation of the **Queue Data Structure** using C++.

## About the Project

This project demonstrates how a Queue works in C++. A Queue follows the **FIFO (First In, First Out)** principle, meaning the first element inserted is the first element removed.

## Features

- Push elements into the queue.
- Pop elements from the queue.
- Demonstrates FIFO behavior.
- Uses a C++ class-based implementation.

## Technologies Used

- C++
- Object-Oriented Programming
- Data Structures and Algorithms

## Example Operations

```cpp
Queue q;

q.push(1);
q.push(2);
q.push(3);
q.push(4);
q.push(5);

q.pop();
q.push(7);
q.pop();
```

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/wajahatmuhammad202-sudo/queue.git
```

2. Open the project folder.

3. Compile the code:

```bash
g++ queue.cpp -o queue
```

4. Run the program:

```bash
./queue
```

On Windows PowerShell, use:

```powershell
.\queue.exe
```
